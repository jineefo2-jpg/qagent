📌 2026 关键趋势
国产模型（MiniMax / Kimi）SWE-bench 已接近 Claude Opus，但价格仅 1/10 ~ 1/20
💡 实战建议
80% 流量走 DeepSeek/Haiku，20% 复杂任务走 Sonnet/Opus，综合成本降低 60-80%
🤖 Agent / 复杂自动化
首选：Claude Sonnet 4.6 / Opus 4.6
SWE-bench 最高，原生 Computer Use + Extended Thinking，工具调用最稳定，Claude Code 是当前 SWE-bench 最高分工具（~80.9%）
次选：GPT-5.4（工具调用可靠，生态最全）
💰 成本敏感 / 高并发
首选：DeepSeek V4 Flash
$0.14/M 输入，约为 Claude Sonnet 的 1/20，SWE-bench 72-74%，多数日常任务够用，开源可私有化部署
次选：Gemini 2.5 Flash（$0.30/M，百万上下文）
🇨🇳 国内合规 / 中文任务
首选：Qwen 3.5 / DeepSeek
国内节点无需代理，支持支付宝付款，Qwen 中文能力国际领先，DeepSeek 开源可本地部署，完全数据自主
次选：GLM-5（国企政府项目合规性更强）
📄 长文档处理 / RAG
首选：Gemini 3.1 Pro / 2.5 Flash
百万 Token 上下文窗口，$2/M 输入价格合理，速度 120 tok/s，适合大文件全文输入的 RAG 架构
国内场景次选：Kimi K2.5（200K 上下文，文档解析强）
🧮 数学 / 科学推理
首选：GPT o3 / DeepSeek R2
o3 在 AIME 数学测试完美得分，但成本高（$10/$40/M）。DeepSeek R2 以 1/10 成本媲美 o3，适合预算有限的推理场景
次选：Claude Opus 4.6（GPQA Diamond 90.5%）
🎨 创意写作 / 产品对话
首选：Claude Sonnet 4.6
写作风格最像人类，"AI 味"最低，指令遵循精准，适合 ToC 产品的自然对话体验
次选：GPT-5.4（叙事结构更清晰，生态更全）
🏗️ ai-service 健康助手（你们项目）
推荐架构：分层路由
简单问答/FAQ → DeepSeek V4（$0.14/M）
症状分析推理 → Claude Sonnet 4.6（$3/M）
关键诊断/复杂多跳 → Opus 4.6（$5/M）
综合成本可降低 60-70%
pgvector + RAG 已有基础，重点打磨 Chunking 和 Reranker
🌍 全球产品 / 多模态
首选：GPT-5.5 / Gemini 3.1 Pro
GPT 生态最全（插件/API/Azure），Gemini 多模态最强（视频理解领先），适合面向全球用户的多语言多模态产品
UAE 合规场景建议走 Azure OpenAI（有中东节点）

💡 没有"最好的模型"，只有"最合适的模型"。建议先用免费额度在真实任务上跑一轮 benchmark，再做选型决策。
