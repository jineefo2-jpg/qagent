🐯 老虎证券 (Tiger Brokers)
📘 绑定指南(展开看 Tiger 配置文件怎么下)
  1. 打开 Tiger OpenAPI 控制台 (用你的老虎账号登录)。
    如果是第一次进,会要你申请 OpenAPI 权限,填一个简短的开发者信息表, 通常即时通过 / 1-2 天审核。
  2. 进入 "密钥管理"(或 "OpenAPI 设置")页面 → 点击 "生成 RSA 密钥对"(已经有的可以"重新生成",但**老旧密钥会立刻作废**)。
  3. 生成后,点 "下载配置文件"。Tiger 通常给的是:
    • tiger_openapi_config.properties — 推荐,包含 tiger_id / 账号 / 私钥 / license 全部字段
    • 或单独的 private_key.pem + 你需要去账户页面抄 tiger_id 和账号
  4. 把那个文件直接拖到下面的灰框,字段会自动填好。无需手抄。
    支持:.properties / .pem / .json / .txt

⚠️ macOS 提示:不要双击 .pem(会被 Keychain Access 接管);也不要用 TextEdit 编辑, 会偷偷存成 RTF 富文本格式让解析失败。
🔒 这个文件全程**只在你浏览器里**解析,不上传到任何服务器(直到你点"测试 + 绑定")。

⬇ 把 .properties / .pem / .json 文件拖进来
或者 点击选文件

② 如果拖拽没解析全,或者只想手动填,下面字段都可以自己改:

-----BEGIN RSA PRIVATE KEY-----
-----END RSA PRIVATE KEY-----

📌 在 Tiger OpenAPI 控制台里复制时,只复制两条 ----- 标签之间的部分; 整段也行,JS 会自动剥掉重复的标签。
🔒 落盘前 Fernet 加密,KEK 在 env 不在 DB,服务端运行时只在内存解密。
