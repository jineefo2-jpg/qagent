🐯 老虎证券 (Tiger Brokers)
  1. 登录 老虎 OpenAPI 控制台,首次申请会要简短开发者信息。
  2. 在控制台 生成 RSA 密钥对 → 下载私钥 .pem(不要在 macOS TextEdit/Notes 里打开,会被改成 RTF)。
  3. 抄下你的 tiger_id + 模拟账号(以 U 开头)。
  4. 把 .pem 内容粘到下面的"私钥"框,填好其它字段提交。

私钥落盘前会被本应用用 Fernet 加密,KEK 不在 DB 里。了解凭证存储

📈 Alpaca (Paper Trading)
  1. 到 Alpaca 注册(走 trading API,不要走 broker-app)。
  2. 登录后切到 Paper Trading 模式 → API Keys → Generate New Key。
  3. 把 Key ID(PK 开头)和 Secret Key 填到下面提交。
